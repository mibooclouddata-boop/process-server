# 남은 보안 보강 및 게시 계획

2026-11-01 사용자의 “전부다 진행하고 완료 시 깃에 푸시” 승인에 따른 후속 작업이다. 이전 계획의 커밋·푸시 금지 범위는 이 요청으로 변경되었다. 운영 요청/실제 Supabase·실데이터 사용 금지와 PR 병합 별도 승인은 유지한다.

- [x] 독립 작업으로 PDF 예산·취소·정리를 구현하고 정상·초과·실패·출력 원자성 회귀를 검사한다.
